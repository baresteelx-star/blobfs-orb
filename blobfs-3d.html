    History

      Blobs drift together by the same similarity the 2D demo uses. A shared tag pulls strongly. The same concrete kind (image with image, audio with audio) pulls weakly. An empty folder does not attract every blob, and different kinds with no shared tag bounce apart. When a similar pair meets, BlobFS proposes the merge and highlights both spheres. Nothing combines until you press Accept, which plays the merge and then commits it with the 2D rules (file+file, dir+dir, file+dir). Refuse pushes them apart and will not propose that pair again. Drag a blob to move it. Drag the empty space to orbit, scroll to zoom. Save Orb / Open .orb use the same .orb zip as blobfs-2d.html. Physics may propose, never commit.
